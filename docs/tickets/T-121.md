## 背景
MS2 核准意見第 5 點：不需要 Docker 的測試也要能在 Windows 執行。`tests/lab/` 代表需要 Docker，所以純函式的分類測試要移出來；labctl 只在 `lock()` 內 import `fcntl`。

## 合約
`rlsentry/contracts/lab.py` 的 `LabCtl.lock` docstring：寫明 `fcntl` 在呼叫時才 import，所以模組在沒有 `fcntl` 的平台上可以 import，只有 `lock()` 會失敗。

## 完成定義
- `tests/lab/test_shared_classify.py` 以 `git mv` 改為 `tests/labctl/test_classify.py`，內容不變。
- `tests/labctl/test_import.py`：把 `sys.modules["fcntl"]` 設為 None 之後重新載入 labctl，必須成功；`write_command` 照常運作；呼叫 `lock()` 時才失敗（ImportError）。測試結束後還原 sys.modules 並重新載入。
- 在 labctl 修正前，test_import.py 必須失敗（TDD）。

## 範圍外
- 修改 labctl（T-122）。
