## 背景
MS0 核准意見第 1 點：setuptools 自動探索在 flat-layout 下找到 lab、logs、host、cloud、harness、rlsentry
多個頂層套件而拒絕安裝。ADR-012 與 MS0 驗證清單第 3 段第 1 項都要求 `pip install -e .[dev]`。

## 完成定義
- pyproject 加 `[build-system]`（setuptools）與 `[tool.setuptools.packages.find] include = ["rlsentry*"]`。
- `tests/packaging/test_pyproject.py`：以 `pip wheel --no-deps --no-build-isolation` 建 wheel（不連網），
  wheel 內只有 `rlsentry/`，沒有 lab、harness、tests、logs、host、cloud。
- 於乾淨 venv 手動驗證 `pip install -e ".[dev]"` 成功（記錄於 PRODUCTION_LOG）。
