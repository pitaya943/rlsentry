## 背景
實測（worktree）發現：(1) run() 對 RPC 目標嘗試寫入 → POST /rest/v1/rpc/... 被寫入閘門擋下（L07 掛掉）；寫入探測必須只對 kind=='table'。(2) 變異測試以「新增 permissive policy to anon」無法在本 lab 讓 anon 真的寫入（anon DELETE 影響 0 列，role 對應細節），改用 `disable row level security`（實測影響 1 列，確定可利用）。

## 完成定義
- `rlsentry/contracts/probe.py` `probe()` 寫入路徑 docstring：明確「只對 kind=='table' 跑寫入路徑；RPC 與 view 的寫入 cell 一律 NOT_TESTED（WRITE_NO_OWNER_REASON），不送請求」。
- `tests/lab/test_write_mutations.py`：兩個變異改用 `alter table public.todos disable row level security`。
- ADR-029 補記記錄。
- `tests/contracts/test_contract_imports.py` 通過；ruff、mypy 無錯。
